授業課題 / Web Site

デザインスクールWebサイト

概要

架空のデザインスクールのWebサイトを制作しました。(PC版のみ)

目的

Web制作初心者や就職・転職を考えている社会人をターゲットに設定し、Web制作への関心を高めるとともに、スクールへの問い合わせ獲得を目的として作成しました。

デザイン・情報設計

デザイン面では、ロゴのカラーを軸にした淡いグラデーションやグラスモーフィズムを取り入れ、柔らかさとトレンド感のある洗練された世界観を演出しました。さらに、余白や丸みのあるデザインで統一し、「見やすさ」と「親しみやすさ」の両立を意識しています。

機能面では、情報量が多い中でも内容をスムーズに理解できるよう、コース紹介はカード型、5つのサポートは円形のレイアウトで整理し、すっきりと見やすい情報設計を行いました。また、トップページから問い合わせページへシームレスに移動できる導線を構築し、フォーム周辺は他のセクションと異なる配色で強調することで、ユーザーの視線を集めて自然な行動へと促す工夫を施しています。

使用ツール

Photoshop / Figma / HTML / CSS

制作期間

約54時間

URL

https://philotoma-dev.github.io/web-school/
