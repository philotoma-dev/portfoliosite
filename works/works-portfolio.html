授業課題 / Web Site

ポートフォリオサイト

概要

就職活動用のポートフォリオサイトを制作しました。

目的

採用担当者様に自身のスキルや制作物をスムーズに伝え、採用の判断材料として活用していただくことを目的に作成しました。

デザイン・情報設計

デザイン面では、全体をシンプルで見やすいレイアウトに統一しつつ、アクセントとしてフィルム調の写真や大好きな海の要素を随所に散りばめました。特にスキルの背景には、jQueryを用いて波紋が浮かぶような動きを加え、シンプルさと自分らしい遊び心を両立させています。

情報設計では、「プロフィール → スキル → 制作物」という採用担当者様が求める情報の流れに沿って構成を整理し、必要な情報へスムーズにアクセスできる導線設計を意識しました。また、制作物をクリックすることで詳細ページへ遷移し、それぞれの概要や目的、こだわりといった詳しい情報を確認できる仕様にしています。

使用ツール

Photoshop / Figma / HTML / CSS

制作期間

約1カ月
